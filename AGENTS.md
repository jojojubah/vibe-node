## Site Structure
- Home page: `/index.html`
- Section pages use folder routes with `index.html`:
  - `/about/`
  - `/games/`
  - `/apps/`
  - `/tools/`
  - `/services/`
  - `/privacy/`
  - `/terms/`
  - `/cookies/`
- Shared static assets live in `/assets/`.

## Shared Files
- Global styles: `/styles.css`
- Global behavior: `/scripts.js`
- Every page includes:
  - `<link rel="stylesheet" href="/styles.css?v=...">`
  - `<script src="/scripts.js?v=..." defer></script>`
- When changing CSS or JS, bump the shared `?v=` cache-buster across all HTML files so updates appear immediately.

## Behavior Notes
- Mobile nav is controlled by `.menu-toggle` `aria-expanded` and header class `menu-open`.
- Hamburger animation is CSS-driven from `.menu-toggle[aria-expanded="true"]`.
- Header scroll behavior uses `.is-scrolled` and `.is-hidden` classes from `/scripts.js`.
- Cookie consent UI is generated by JS and stored in localStorage key:
  - `vibenode_cookie_consent_v1`
- Footer links with `.cookie-settings-link` trigger the cookie settings panel.

## Editing Rules
- Keep clean folder URLs (edit `*/index.html`, not `.html` route files at root).
- Preserve shared header/footer structure and navigation consistency across pages.
- Preserve accessibility attributes used by JS (`aria-expanded`, `aria-controls`, `aria-hidden`).
- Prefer existing design tokens and section patterns in `/styles.css`.
- Keep paths consistent:
  - Root page currently uses `assets/...` for many in-page images.
  - Nested pages use `/assets/...`.

## Quick QA Checklist
- Desktop and mobile navigation opens/closes correctly.
- Active nav state (`aria-current="page"`) is correct on section pages.
- Cookie banner appears for first-time visitors, and settings open from footer link.
- No broken links for folder routes.
- Updated CSS/JS changes appear after version param bump.

## Local Preview
- Run a simple static server from repo root, for example:
  - `python3 -m http.server 8000`
- Open `http://localhost:8000/` and validate key routes.
